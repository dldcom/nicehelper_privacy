개인정보 처리방침

시행일·최종 수정일: 2026년 10월 7일

학생 개인정보를 개발자의 서버·외부 DB·AI 서비스로 전송하지 않습니다.

학생 개인정보와 학생별 평가 기록은 기기 안에서 처리합니다. 공통 평가 기준·문구는 서버·D1·AI에서 문장 후보 생성·저장에 사용합니다. 사용자가 입력·저장을 실행한 내용은 로그인한 나이스에 반영됩니다.

1. 적용 범위와 핵심 원칙

이 방침은 평어 후보 서버·DB·AI 연결 기능을 포함한 NICEHELPER Chrome 확장프로그램의 자료 처리에 관한 설명입니다. 시행일과 최종 수정일은 2026년 10월 7일입니다.

NICEHELPER는 학생 개인정보와 학생별 평가 기록을 개발자의 서버·외부 데이터베이스·AI 서비스로 전송하지 않습니다. 이 자료는 사용자의 기기 내부에서 처리합니다. 종합의견의 공통 문장 후보를 만들기 위한 평가계획의 공통 기준·문구는 서버·DB·AI에서 처리합니다. 사용자가 입력·저장을 실행한 자료는 로그인한 나이스 화면을 통해 나이스에 반영됩니다.

나이스 서비스의 자체 저장·처리는 해당 서비스의 정책에 따릅니다. 학생 개인정보의 외부 전송 없음은 모든 자료를 외부로 보내지 않는다는 뜻이 아닙니다. 서버·DB·AI로 전송하는 공통 평가 자료의 범위와 이용 목적은 아래에 구분하여 설명합니다.

2. 기능 수행을 위해 처리하는 자료

평가계획·시간표: 사용자가 선택한 파일에서 분석한 성취기준, 평가기준, 단계별 평가결과, 교과·시간표 내용과 관련 설정을 처리합니다. 원본 파일을 개발자에게 업로드하지 않습니다.

출결·관찰: 나이스에서 확인한 학생 이름·번호와 학년도·학년·반, 사용자가 작성한 날짜·출결 종류·사유·관찰 내용, 기록 대상과 입력 결과를 처리합니다. 질병결석 사유 등 사용자가 입력한 건강 관련 내용이 포함될 수 있습니다.

교과평가·종합의견: 나이스의 학교·학기·학급 정보, 학생 목록, 평가계획·학생별 평가결과·기존 의견, 평가 선택값·의견 초안과 작업 백업을 처리합니다.

업무 연결: 현재 연결한 나이스의 출처 주소, 탭·프레임·문서 식별 정보와 작업 상태를 처리합니다. 일반 웹사이트 방문 이력, 광고 식별자나 일반 이용 행동을 추적하지 않습니다.

나이스 로그인은 나이스에서 직접 이루어집니다. 확장프로그램은 사용자 비밀번호, 인증서, 인증 토큰을 읽어 저장하는 기능을 제공하지 않습니다.

3. 자료의 이용 목적

처리한 자료는 학생 매칭, 파일 분석, 평가표 작성, 출결·관찰 기록 검토, 종합의견 초안 작성, 사용자가 실행한 나이스 입력·저장, 작업 상태 확인과 초안 복원에 사용합니다.

학생 자료를 광고, 판매, 프로파일링, AI 모델 학습 또는 해당 업무 기능과 관계없는 목적에 이용하지 않습니다.

4. 저장 위치와 보관 기간

지속 보관: 학생 목록, 학급별 출결·관찰 초안과 입력 결과, 현재 평가계획 및 일부 설정은 Chrome의 기기 내부 저장소(chrome.storage.local)에 보관합니다. 정해진 자동 만료 기간은 없으며 확장 삭제, 해당 자료 삭제·교체 또는 브라우저 프로필 삭제 등으로 없어질 수 있습니다. 확장을 업데이트하거나 브라우저를 다시 열어도 지속 보관 자료는 일반적으로 유지됩니다.

임시 보관: 평가 작업의 연결 자료, 평가표·종합의견 초안, 작업 상태와 백업 등은 chrome.storage.session 또는 실행 화면의 메모리에 보관합니다. 세션 저장 자료는 브라우저 재시작, 확장 비활성화·새로고침·업데이트 시 삭제됩니다. 패널이나 독립 창의 메모리 자료는 해당 실행 화면 종료에 따라 사라질 수 있습니다.

학생 개인정보와 학생별 평가 기록은 Chrome의 storage.sync를 이용해 동기화하거나 개발자 운영 클라우드·외부 데이터베이스에 백업하지 않습니다.

서버 보관: 공통 평가 자료와 생성된 공통 문장 후보는 Cloudflare D1 데이터베이스에 저장하여 같은 평가의 후보를 재사용합니다. 서버의 자료 삭제·갱신 시까지 재사용 목적으로 보관하며, 사용자의 브라우저 종료나 확장프로그램 제거만으로 서버 자료가 삭제되지는 않습니다.

학생 자료의 기기 내 저장은 Chrome의 기본 저장 기능을 이용하며, 확장프로그램이 별도의 저장 암호화를 제공한다고 주장하지 않습니다.

5. 외부 DB·AI 서비스 전송과 나이스 입력

평어 후보 서버 연결 기능을 사용하면 평가계획의 학년·과목·영역·성취기준·평가요소·평가단계와 단계별 공통 평가결과 문구를 Cloudflare Worker 서버로 전송합니다. 이 자료는 Cloudflare D1 데이터베이스에 저장되며, 공통 문장 후보를 생성하는 AI의 입력으로 사용됩니다.

학생 이름·번호·명단, 학교·반, 학생별 평가단계 배정·개별 평가결과, 출결 사유·관찰기록·기존 종합의견·학생별 초안은 서버·D1·AI에 전송하지 않습니다. 전송되는 단계별 공통 평가결과는 평가계획의 공통 문구이며, 특정 학생에게 배정된 평가 기록과 구분됩니다.

AI는 공통 평가 자료를 참고하여 단계별 문장 후보를 만들고, 서버는 그 후보를 저장·재사용합니다. 학생별 평가에 맞는 후보 선택·조합과 학생 이름을 포함한 초안 작성·수정은 기기 내부에서 처리합니다. 서버에 연결하지 않는 경우에는 기기 내부 규칙으로 공통 평가 문구를 조합·변형하여 초안을 만듭니다.

사용자가 나이스 입력·저장 기능을 실행하면 해당 자료를 나이스 업무 화면에 입력하고, 지원되는 기능은 나이스의 조회·저장 동작을 실행합니다. 나이스로의 입력·저장은 사용자가 요청한 업무의 목적에 한해 이루어집니다.

자료를 판매하거나 광고·프로파일링 목적으로 제공하지 않습니다. 공통 평가 자료의 외부 처리는 문장 후보 생성·저장·재사용을 위해 이루어지며, 학생 개인정보는 이 처리에 포함하지 않습니다. 확장프로그램 자체의 광고, 분석 추적기, 외부 오류 보고 서비스를 사용하지 않습니다.

6. 확인·수정·삭제

사용자는 확장프로그램 화면에서 학생 목록과 기록을 확인하고 지원되는 편집·삭제 기능을 사용할 수 있습니다. 학생 목록을 다른 학급으로 바꾸면 이전 학급 초안이 기기에 남아 있을 수 있으므로, 전체 자료 삭제와 동일하지 않습니다.

기기에 저장된 확장 자료 전체를 삭제하려면 Chrome의 확장프로그램 관리 화면에서 NICEHELPER를 제거하세요. 다시 사용하려면 재설치하고 필요한 자료를 새로 가져오면 됩니다. 일반 방문 기록·캐시를 지우는 것만으로 확장 저장 자료가 모두 삭제되지는 않습니다.

확장에서 기록을 삭제하거나 확장을 제거해도 이미 나이스에 입력·저장된 자료는 삭제되지 않습니다. 해당 자료의 수정·삭제는 나이스에서 수행해야 합니다.

개발자는 사용자의 기기 내부 학생 자료를 보관하거나 열람하지 않으므로 해당 자료를 대신 조회·복구·삭제할 수 없습니다. 문의 시에도 실제 학생 개인정보를 포함하지 마세요.

7. 권한과 처리 범위

나이스 주소 범위(https://*.neis.go.kr/*)에 접근해 해당 업무 화면과 자료를 확인하고 요청한 입력을 실행합니다. 평어 후보 서버 연결 기능에서는 연결한 서버에 대한 접근 권한을 추가로 요청하며, 해당 서버와 공통 평가 자료·문장 후보를 주고받는 데 사용합니다.

sidePanel은 업무 패널 표시, storage는 로컬·임시 자료 보관, scripting은 확장에 포함된 코드의 나이스 화면 주입, webNavigation은 나이스 프레임·문서 연결과 화면 교체 감지를 위해 사용합니다.

8. 방침 변경과 서비스 구분

자료 처리 방식, 전송 범위 또는 연결 서비스가 변경되면 이 페이지의 방침과 수정일을 갱신합니다. 학생 개인정보의 기기 내 처리와 공통 평가 자료의 서버·DB·AI 처리를 구분하여 안내합니다.

Chrome 웹스토어와 이 안내 페이지의 호스팅 서비스 운영자가 자신의 서비스 이용 과정에서 처리하는 정보는 각 운영자의 정책에 따릅니다. 해당 서비스에 NICEHELPER의 학생 자료를 전달하는 기능은 없습니다.

NICEHELPER는 교육부·교육청·나이스의 공식 제품이 아닌 독립적인 업무 보조 확장프로그램입니다.

9. 운영자와 문의

운영 주체: Chrome 웹스토어 NICEHELPER 항목에 표시된 개발자.

문의 방법: Chrome 웹스토어 NICEHELPER 상세 페이지의 개발자 연락처 또는 지원 항목을 이용해 주세요. 문의에 학생 이름, 출결 사유, 관찰기록이나 실제 학교 자료를 첨부하지 마세요.
